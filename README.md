# Hi, I'm Jinyu 👋

I'm building systems around **AI agents, evaluation, and workflow reliability**.

My current main project is **Agent Boundary Lab (ABL)** — a deterministic verifier for multi-step research-agent workflows.

ABL focuses on questions like:

- Can a final output be traced back to recorded evidence?
- Was human review actually recorded where required?
- Is the workflow auditable and reproducible?
- What assurance gaps remain when context is missing?

## Current focus

- Research-agent workflow assurance
- Evidence lineage and provenance
- Agent evaluation and adversarial verification
- Real-world trace integration
- Reliable AI systems
